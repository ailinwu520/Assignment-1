# Dogs vs Cats Classification 🐶🐱

A Convolutional Neural Network (CNN) model to classify images of **dogs** and **cats** using the [Kaggle Dogs vs Cats dataset](https://www.kaggle.com/c/dogs-vs-cats). This project demonstrates image classification using **PyTorch** and **transfer learning** with ResNet18.


## Project Overview

The goal of this project is to build an image classification model that can distinguish cats from dogs. 
The notebook includes both:
- A simple CNN model  
- A transfer learning model using pretrained ResNet18  


## Dataset

- **Source:** [Kaggle Dogs vs Cats](https://www.kaggle.com/c/dogs-vs-cats)  
- **Train images:** 25,000 labeled images  
- **Test images:** Unlabeled images for submission  
- **Sample Submission:** CSV file for Kaggle predictions
